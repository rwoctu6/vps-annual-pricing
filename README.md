# 年付vps：把7折、套餐阶梯和退款规则算清楚，再决定哪台机器值得一次付一年

年付 VPS 真正难的不是"哪儿便宜"，而是"这笔钱押一年值不值"。

一台 25 元/月的入门机，年付只要 210 元，账面上省了 90 元；但如果买回来的线路晚高峰卡成幻灯片，或者配置买小了没法改，省下的 90 元就是打水漂。所以这篇文章不讲"年付真香"，讲三件事：年付的折扣到底是怎么算出来的、机器在中途能不能改、以及哪些情况下年付是可以退的。

以雨云为例，它的折扣规则写得比较直白：**季付 9 折、半年付 8 折、年付 7 折**。这套折扣覆盖云服务器、游戏云、对象存储等主要产品线，也是我们后面所有价格计算的基准。

## 年付比月付到底便宜多少

年付便宜的本质是商家拿现金流。你一次付清 12 个月，它不用每个月追续费，用户流失率下降，所以愿意让出 20%–30% 的价格。雨云的让价幅度是 30%，比行业里常见的 8 折整整多出一档。

把同一个机型放到四种计费方式里对比，差距一目了然：

| --- | --- | --- |
| 月付 | 无 | 300 元 |
| 季付 | 9 折 | 270 元 |
| 半年付 | 8 折 | 240 元 |
| 年付 | 7 折 | **210 元** |

同一句"年付更划算"，落在具体数字上是 300 元和 210 元的区别，折合约 17.5 元/月。这个价位能跑一个静态站、做个代理中转、挂个小程序后端或者当开发测试机，都算合理。

## 付一年之前，先把这四件事确认掉

### 1. 退款窗口有多长

雨云的口径是**开通后 7 天内无理由退款，单个账号限 3 次**。这意味着你有一个星期的时间去测延迟、测丢包、测磁盘 IO。七天测不出花来，但足够判断这台机器是不是明显不合适。

### 2. 能不能先试再买

云服务器和游戏云支持 **1 元试用 1 天**，裸金属物理机则是 20 元试用一天。低配机型试一天花 1 元，高配机型试用价格会相应上浮。对第一次用某个机房的人，这 1 元比看十篇测评都管用。

### 3. 中途想改配置怎么办

这是年付最大的隐忧。雨云的机制是：可以**按天补差价升级套餐、弹性扩容云盘、加购独立 IP、迁移机房区域**。也就是说年付锁的是价格，不是配置——买小了还能往上加。

扩容云盘的计费方式是按天算，公开口径约 3.6 元/10GB/月，比一次性买大硬盘更灵活。硬盘基础容量 30GB 起步，最高可以扩到 2000GB 级别。

### 4. 流量超了会怎样

雨云把大带宽机型分两种卖法：

- **小带宽不限流量型**：带宽固定，流量随便跑。
- **大带宽限流量型**：带宽给得高，但有月流量额度。

限流量机型用完额度后**不会停机，而是限速**（常见是降到 5Mbps，部分区域机型限速值更低），可以另外买流量包恢复高速。而且当月没用完的流量可以结转到下个月，不清零。这个设计对建站用户友好——网站被刷流量的时候你损失的是速度，不是服务器本身。

> 关于国内高防机房：独立 IP 是另外计费的，国内几个高防机房的独立 IP 价格明显高于海外机房。如果你打算在国内机房建站，必须把独立 IP 的费用算进年付预算，下单前先在配置页确认价格。

## 哪些人适合年付，哪些人先别急

适合年付的情况很明确：你已经确定这台机器会连续用满 12 个月——个人博客、长期挂着的服务、固定的测试环境、朋友之间长期开的游戏服。7 折省下来的钱是实打实的，210 元对比 300 元，等于白送三个月机器。

先别年付的情况同样清楚：

- **第一次用这个商家**。先月付，把线路和稳定性测一遍，7 天退款窗口和 1 元试用都是为这个准备的。
- **业务量还没定**。配置买大了浪费，买小了要补差价升级——虽然可以升，但过程中要折腾，不如先月付摸清用量。
- **对线路质量敏感但没测过**。不同机房、不同线路的晚高峰表现差异很大，第三方测评只能参考，最终还得看你的用户在哪。
- **预算紧且不能承担一次付一年的风险**。这一点不用避讳，年付的风险就是钱先出去。

## 常见问题

**年付了还能退款吗？**
可以，开通后 7 天内无理由退款，每个账号限 3 次。超过窗口期就按正常规则处理了，所以决定要退就别拖。

**年付之后能升级配置吗？**
可以。升级套餐、扩容云盘、加购独立 IP 都是按天补差价，操作在控制台里完成，不用重新买一台机器。

**年付的流量用完了会关机吗？**
不会。限流量机型用完额度会限速，可购买流量包恢复；不限流量机型本身就没有额度限制。没用完的流量可以结转到下个月。

**国内机房需要备案吗？**
国内机房用于建站走正常备案流程；香港、日本、美国等海外机房免备案。

**年付最低多少钱能入门？**
美国机房 1 核 1GB 入门版，年付 7 折后 210 元，折合约 17.5 元/月，是目前比较低的一条入门线，支持一键安装宝塔、1Panel 等面板环境。

**支持 Windows 吗？**
支持，KVM 虚拟化，Linux 和 Windows 系统都可以装，部分地区还提供额外系统选项，具体以购买页的系统列表为准。
